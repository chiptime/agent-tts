# Live call streaming — milestone 1

Objective: a local, Gemini-Live-class call — always-open mic, live transcription, semantic end of turn — as the opt-in "Dictado: En vivo" engine.
Branch: `feat/live-call-streaming` · Delivery: `exception-ok` (D17: one feature branch, work-unit commits, operator merges to main after Pixel acceptance; no PRs) · Test runner: `hosts/herdr/brain/.venv/bin/python -m pytest` from `hosts/herdr/brain`, `node --test tests/js`.

## Specs

Source of truth for decisions: `hosts/herdr/brain/docs/live-call/ROADMAP.md` §11 (D1–D17) and PRD-03/04/05 "Closed Decisions".

- **S1** — The call hears from the first word, with no wake-up phrase. User: "Tengo que hablar primero para que sepa que estoy hablando. Con eso. Ya se come una frase y a partir de ahí no." Goal: "poder tener una llamada como en Jamie" (Gemini Live). Scope: PRD-03 uplink — WebSocket `/call/stream`, AudioWorklet PCM16 16 kHz mono, first-message device-token auth, bounded backpressure, in-memory ring buffer only (D9).
- **S2** — Opt-in engine "Dictado: En vivo" next to Servidor and Navegador, both untouched; default only after Pixel acceptance (D15).
- **S3** — Failure path: a failing/dropped socket falls back automatically to Servidor segments with a visible notice, never dropping the call; an unreachable brain refuses to start the call (D1).
- **S4** — Transcription with faster-whisper `large-v3` from llm-hub's model files by local path, no download (D7, D12); on the GPU sharing VRAM with Qwen, degrading to `small` with a notice when VRAM is short; headroom measured (D13).
- **S5** — Live partial text while speaking; finals compatible with today's turn text; language forced to the app locale plus an editable technical-vocabulary hint (D8, D9). Raw audio never stored (D9).
- **S6** — End of turn decided by Silero VAD framing plus a LOCAL completion detector; GLM only as a measured tie-breaker (D2); never cutting the speaker wins over speed, first audio ≤ 1.5 s (D3); energy VAD kept as fallback (PRD-05).
- **S7** — Speech that resumes after a close but before the answer starts rejoins the same turn (cancel in-flight ask, re-dispatch whole) (D10).
- **S8** — Screen on during the call via wake lock (D5).
- **S9** — Acceptance (operator, Pixel 7 Pro): 20 natural turns with deliberate pauses and zero cuts, first phrase intact, first audio ≤ 1.5 s, 5-minute call with no lost turn (D11). Assumption accepted: phone reaches the PC over Tailscale; one streaming device per call.
